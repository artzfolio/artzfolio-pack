⬆ Bulk CSV Import — Update Existing SKUs

Upload a CSV with a sku_code column plus any of reorder_threshold, cost_price, mrp, active (true/false). Only these four fields can be changed here — new SKUs are not created, and product name / ASIN / bin / set size are not touched, even if present in your file (extra columns are simply ignored).
Bin Management
Every bin currently on file, with live SKU count and quantity. Rename/merge moves stock via new transfer transactions - it never edits history.
Bins are not a fixed list - typing a brand-new bin code anywhere in the app, the bulk Excel tool, or the "New Bin" field below creates it automatically the moment it's first used. This screen exists to catch typos before they become phantom bins, and to consolidate or retire bins that are no longer needed.

Moves ALL current stock out of the old bin and into the new bin. If the new bin doesn't exist yet, it is created automatically. This writes new transfer transactions - it never edits history, and the old bin's past transactions still show it as the bin used at the time.
