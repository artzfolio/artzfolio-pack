Phones
Every phone that has ever signed in or scanned. Give each one a name you recognise, and block one the moment it should no longer be used.
What blocking a phone does, and what it does not.
A blocked phone cannot sign in, cannot start a scanning batch, and — if it is already signed in — is signed out automatically the next time the app checks, which is within about a minute while it is in use, or the moment it is picked up again. Use it when a phone is lost, handed back, or should simply not be used any more. Anything it already scanned stays exactly as it is; blocking stops further work, it never undoes any.
It is not the main control for someone leaving. Each phone invents its own code the first time the app runs, so clearing the app's data on that phone produces a new code and a fresh start. When a person leaves, switch their staff account off under User Management — that stops them signing in anywhere, on any phone. Blocking the handset is a useful extra, not a replacement.

⬆ Bulk CSV Import — Update Existing SKUs

Upload a CSV with a sku_code column plus any of reorder_threshold, cost_price, mrp, active (true/false). Only these four fields can be changed here — new SKUs are not created, and product name / ASIN / bin / set size are not touched, even if present in your file (extra columns are simply ignored).
